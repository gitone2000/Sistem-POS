SukaPOS

Multi Store Point Of Sales

  • created: 03/10/2011
  • latest update: 10/25/2018
  • by: Sukadroid Dev
  • email: info@sukadroid.com

SukaPOS adalah aplikasi Point Of Sales yang mendukung beberapa toko sekaligus. Dengan SukaPOS, anda mampu menangani beberapa tagihan sekaligus, menahan tagihan (hold), mencari produk langsung dari layar POS, mendukung Barcode Scanner, dan masih banyak lagi.

Terima kasih telah membeli produk kami. Jika anda memiliki pertanyaan yang berada di luar lingkup file bantuan ini, silakan kirim email ke info@sukadroid.com. Terima kasih banyak!













  • Software Version: 2.0.1
  • Software Framework : Codeigniter 3.0.1
  • PHP Version : 5.6
  • Responsive Design : Yes

Instalasi

Setelah anda mendownload project, silahkan upload semua file & folder yang terdapat di Folder Project ke Direktori Server anda.

Perlu diingat bahwa SukaPOS dapat berjalan Online maupun di Server Lokal.

 

.htaccess

Buat file .htaccess di Direktori Server anda, dan masukan kode berikut :

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php/$1 [L]

 

Base URL

Buka folder application/config/config.php dan cari $config['base_url'] = 'http://........ di line 27 dan ubah menjadi URL project anda.

 

Setting Database

Buat database di Phpmyadmin dan berikan nama sesuai keinginan anda, dan import sukapos.sql yang ada di direkrtori project kedalam database yang baru anda buat.

Selanjutnya buka application/config/database.php dan sesuaikan nama database dan koneksi database anda.
